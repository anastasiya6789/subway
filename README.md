# Rail Rush

3D-раннер по рельсам для браузера (Three.js, без сборки). Чистые статические файлы, поэтому игра работает и на localhost, и на GitHub Pages.

## Запуск локально

```bash
cd ~/Desktop/subway
python3 -m http.server 8080
```

Открой http://localhost:8080. Открывать `index.html` двойным кликом нельзя: ES-модули не грузятся через `file://`.

## Управление

| | ПК | Телефон |
|---|---|---|
| Влево / вправо | `A` / `D` (или ← →) | свайп ← → |
| Прыжок | `W` / `↑` / `Пробел` | свайп ↑ |
| Подкат (в воздухе — резкий спуск) | `S` / `↓` | свайп ↓ |
| Пауза | `P` / `Esc` | кнопка ❚❚ |

Клавиши привязаны к физическим кнопкам, поэтому WASD работает и на русской раскладке.

## Препятствия

- **Низкий барьер** — перепрыгнуть.
- **Высокий шлагбаум** с красной лампой — подкатиться.
- **Поезд** — уйти в другую полосу.
- **Поезд с рампой** — забежать по рампе и бежать по крышам.
- **Встречный поезд** (жёлтые фары) — едет навстречу, увернуться заранее.
- Удар боком — спотыкаешься; второй удар за ~3 секунды — проигрыш.

## Магазин

Монеты, собранные за забег, копятся на счёте. Их можно потратить в магазине:

- **Скины:** 7 образов персонажа, от «Ниндзя» за 600 до «Золотого» за 10 000.
- **Прокачка:** у каждого бонуса 5 уровней, каждый добавляет +20% к длительности. Цены уровней: 300 / 700 / 1500 / 3000 / 6000.
- **Предметы:**
  - ❤️ Второй шанс (400): после удара можно продолжить забег, не больше 2 раз за забег.
  - 🛡️ Стартовый щит (250): включается в начале следующего забега.

## Аккаунты и рейтинг

Без настройки игра работает в **гостевом режиме**: прогресс хранится в браузере, а рейтинг показывает «не подключён».
Если гость зарегистрируется, его монеты и покупки перейдут в аккаунт.

Чтобы включить регистрацию и онлайн-рейтинг, нужен бесплатный проект Firebase (тариф Spark):

1. Зайди на https://console.firebase.google.com и нажми **Create a project**. Google Analytics можно отключить.
2. **Build → Authentication → Get started → Sign-in method → Email/Password** → включи первый переключатель и нажми **Save**.
3. **Authentication → Settings → Authorized domains → Add domain**: впиши `anastasiya6789.github.io`. `localhost` там уже есть.
4. **Build → Firestore Database → Create database**: выбери регион (например `eur3`) и режим **production**.
5. **Firestore → вкладка Rules**: вставь содержимое файла `firestore.rules` из этой папки и нажми **Publish**.
6. **⚙️ Project settings → General → Your apps → значок `</>`**: зарегистрируй веб-приложение (Hosting не нужен) и скопируй объект `firebaseConfig`.
7. Вставь его в `firebase-config.js` вместо `null`, затем закоммить и запушь.

Ключ `apiKey` в веб-конфиге Firebase не секретный, его можно хранить в публичном репозитории. Данные защищают правила из `firestore.rules`: каждый игрок может менять только свой профиль, ник менять нельзя, а рекорд может только расти.

Ограничения:
- Вход идёт по нику и паролю, без почты, поэтому **забытый пароль не восстановить**.
- Очки считаются в браузере игрока, поэтому знающий человек может накрутить рекорд через DevTools. Для игры с друзьями это не страшно, а честная защита требует серверной проверки.

## Деплой на GitHub Pages

```bash
cd ~/Desktop/subway
git init
git add .
git commit -m "Rail Rush"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

Дальше на GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**. Через минуту игра будет на `https://<твой-ник>.github.io/<репозиторий>/`.

## Файлы

- `index.html` — разметка и меню
- `style.css` — интерфейс
- `game.js` — сама игра (сцена, генерация трассы, физика, бонусы, управление, звук)
- `profile.js` — профиль игрока, сохранение, Firebase, покупки
- `meta.js` — экраны магазина, рейтинга и входа
- `firebase-config.js` — сюда вставляется конфиг Firebase
- `firestore.rules` — правила безопасности базы
