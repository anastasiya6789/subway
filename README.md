# Rail Rush

3D-раннер по рельсам для браузера (Three.js, без сборки). Чистые статические файлы, поэтому игра работает и на localhost, и на GitHub Pages.

## Запуск локально

```bash
cd ~/Desktop/subway
python3 -m http.server 8080
```

Открой http://localhost:8080. Открывать `index.html` двойным кликом нельзя: ES-модули не грузятся через `file://`.

## Управление

| | ПК | Телефон |
|---|---|---|
| Влево / вправо | `A` / `D` (или ← →) | свайп ← → |
| Прыжок | `W` / `↑` / `Пробел` | свайп ↑ |
| Подкат (в воздухе — резкий спуск) | `S` / `↓` | свайп ↓ |
| Пауза | `P` / `Esc` | кнопка ❚❚ |

Клавиши привязаны к физическим кнопкам, поэтому WASD работает и на русской раскладке.

## Препятствия

- **Низкий барьер** — перепрыгнуть.
- **Высокий шлагбаум** с красной лампой — подкатиться.
- **Поезд** — уйти в другую полосу.
- **Поезд с рампой** — забежать по рампе и бежать по крышам.
- **Встречный поезд** (жёлтые фары) — едет навстречу, увернуться заранее.
- Удар боком — спотыкаешься; второй удар за ~3 секунды — проигрыш.

## Бонусы

| | Бонус | Действие |
|---|---|---|
| 🧲 | Магнит | 10 с, притягивает монеты со всех полос |
| 🚀 | Джетпак | 7 с, полёт над поездами, в небе дорожка монет |
| 👟 | Пружинки | 10 с, суперпрыжок, можно запрыгнуть прямо на крышу поезда |
| x2 | Очки x2 | 12 с, двойные очки |
| ⏳ | Слоу-мо | 6 с, мир замедляется, ты нет |
| 🛡️ | Щит | 25 с, спасает от одного удара |
| 🎁 | Сюрприз | случайный бонус или пачка монет |

Рекорд и сумма монет хранятся в localStorage браузера.

## Деплой на GitHub Pages

```bash
cd ~/Desktop/subway
git init
git add .
git commit -m "Rail Rush"
git branch -M main
git remote add origin https://github.com/<твой-ник>/<репозиторий>.git
git push -u origin main
```

Дальше на GitHub: **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**. Через минуту игра будет на `https://<твой-ник>.github.io/<репозиторий>/`.

## Файлы

- `index.html` — разметка и меню
- `style.css` — интерфейс
- `game.js` — вся игра (сцена, генерация трассы, физика, бонусы, управление, звук)
